# От нейрона к агенту

Интерактивный доклад о LLM и AI-агентах. Один сайт работает в двух режимах:

- презентация — крупные слайды, клавиатурная навигация и интерактивы;
- чтение — полный текст, заметки спикера и библиография.

## Редактирование доклада

Основной материал находится в [`content/talk.ru.md`](content/talk.ru.md).
Каждый блок между `===` — отдельный слайд. В начале блока находятся его
метаданные, ниже — текст для читателя, а после `<!-- notes -->` — заметки
спикера. Ссылки записываются как `[12]`.

Список источников и их номера находятся в
[`content/references.json`](content/references.json). Генерируемый файл
`content/generated.ts` вручную менять не нужно.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка автоматически проверяет уникальность слайдов, существование источников
и общий хронометраж. Дополнительные демонстрационные данные также воспроизводимы:
токены строятся локальным токенизатором, а сеть распознавания цифр обучается
скриптом при сборке.

```bash
npm test
```

Управление в режиме презентации: стрелки, `Page Up` / `Page Down`, пробел;
`O` открывает обзор, `R` переключает режим чтения.
