# От нейрона к агенту

Интерактивный доклад о LLM и AI-агентах. Один сайт работает в двух режимах:

- презентация — крупные слайды, клавиатурная навигация и интерактивы;
- чтение — полный текст, заметки спикера и библиография.

## Редактирование доклада

Основной материал находится в [`content/talk.ru.md`](content/talk.ru.md).
Каждый блок между `===` — отдельный слайд. В начале блока находятся его
метаданные, ниже — текст для читателя, а после `<!-- notes -->` — заметки
спикера. Ссылки записываются как `[12]`.

Углублённый бонусный маршрут про устройство Transformer находится отдельно в
[`content/bonus-transformer.ru.md`](content/bonus-transformer.ru.md). Он устроен
точно так же, но все его слайды автоматически попадают только в бонусный раздел
обзора и режима чтения.

Первый блок `cover` также управляет общими данными страницы:

- `brand` — короткая надпись в шапке;
- `kicker` — тип материала, например «Интерактивный доклад»;
- `title` — название доклада и HTML-заголовок страницы;
- `subtitle` — подзаголовок на обложке, в режиме чтения и description страницы.

Текст внутри интерактивных схем, графиков и таблиц находится в
[`content/visuals.ru.json`](content/visuals.ru.json). Примеры для демонстрации
токенизации редактируются в
[`content/token-samples.ru.json`](content/token-samples.ru.json).
Данные учебных схем Transformer находятся в
[`content/transformer-visuals.ru.json`](content/transformer-visuals.ru.json).

Список источников и их номера находятся в
[`content/references.json`](content/references.json). Генерируемый файл
`content/generated.ts`, `content/token-samples.json` и модель цифр вручную
менять не нужно.

После изменения Markdown перезапустите локальную версию:

```bash
make down
make up
```

### Правка прямо в докладе

В локальном dev-режиме в шапке доступна кнопка «Редактировать текст». Можно
править заголовки, подзаголовки, основной текст и заметки спикера прямо в
слайде или режиме чтения. После выхода из поля изменения автоматически
записываются в исходный Markdown-файл и пересобирают `content/generated.ts`.
Основной маршрут сохраняется в `content/talk.ru.md`, бонусный — в
`content/bonus-transformer.ru.md`.

Редактор и локальный endpoint сохранения не включаются в production-сборку.

## Локальный запуск

```bash
npm install
make up
```

Презентация будет доступна на <http://localhost:3001>. Остановка:

```bash
make down
```

Дополнительно: `make status` показывает состояние процесса, `make logs` —
поток локального dev-лога. Порт можно переопределить: `make up PORT=3100`.

Сборка автоматически проверяет уникальность слайдов, существование источников
и общий хронометраж. Дополнительные демонстрационные данные также воспроизводимы:
токены строятся локальным токенизатором, а сеть распознавания цифр обучается
скриптом при сборке.

```bash
npm test
```

Управление в режиме презентации: стрелки, `Page Up` / `Page Down`, пробел;
`O` открывает обзор, `R` переключает режим чтения.
